# Your first 10 minutes

Once you have Ryoku Nix installed, here are some useful things to do to make the experience easier for new users.

## 1. Find your way around

- **App launcher:** Opens a searchable list of programs, by default the shortcut is **Super + Space**. The Super key is the key with the Windows logo, on  MacBooks, iMacs and other Apple computers this is the **Command Key**
- **Ryoku Hub:** The central place for all desktop settings, customization including animations, compositor, barstyles, notification sounds and appearance settings.
- **Quick settings:** A panel for everyday controls, such as audio, in depth CPU, RAM, Network charts, connectivity and session actions. This menu is opened via the **Super + Esc** keys.
- **RyoStore:** A community made store made for the sole purpose of making Ryoku the most customisable shell to ever exist including, Bars, Fastfetches, Lockscreen and other Ryoku customisations.

## 2. Try opening an application

Open the application launcher, type the name of an installed program and select it. The app launcher is like the Windows Start menu with more search options and functions similarly to the alt + space runner found on Microsoft Powertoys but faster and more in depth.

## 3. Open Ryoku Hub

The Ryoku Hub is the one single app that controls all of Ryoku, there are alot of pages and tweaking you can do here but start off simple and understand what each thing does before tweaking every single aspect of the shell and getting confused. We recommend the first things to look at is the Profile and Keybinds tab.

## 4. Make one noticeable change

Use **Ryogami** with **Super + W**, pick a wallpaper, rice, theme or even a Wallpaper Engine wallpaper, once it is applied you may notice alot of the desktop has also changed colours such as the terminal, Ryoku apps etc. This is called `Matugen` and it completely themes your entire desktop around a chosen wallpaper.

## 5. Learn one safety habit

On NixOS, configuration changes can create **generations**, or saved system versions you can return to. Read [Updates and rebuilds](updates.md) and [Recovery](recovery.md) before a major system update.
