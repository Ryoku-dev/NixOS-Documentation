# Your first 10 minutes

You're on the Ryoku desktop. You do not have to change everything immediately. Here are the useful places to start.

## 1. Find your way around

- **App launcher:** Opens a searchable list of programs. On many Ryoku configurations the shortcut is **Super + Space**. The Super key is usually the key with the Windows logo.
- **Ryoku Hub:** The central place for many desktop and appearance settings.
- **Quick settings:** A panel for everyday controls, such as audio, connectivity and session actions.
- **RyoStore:** Browse supported themes, bar styles, launchers and other Ryoku customisations.

Your selected bar or launcher style may move buttons around. That is normal.

## 2. Try opening an application

Open the application launcher, type the name of an installed program and select it. A launcher is like the Windows Start menu with more search options.

If you cannot find a particular app, it may simply not be installed. Read [Apps and software](applications.md) before trying random installation commands from the internet.

## 3. Open Ryoku Hub

Start with the appearance and desktop pages. Look at the available options without changing five different settings at once. A sensible first change is a wallpaper.

## 4. Make one visual change

Use **Ryogami** or the wallpaper controls available in your Ryoku build. Pick a wallpaper and observe how supported elements of the desktop change colours to match it.

## 5. Learn one safety habit

On NixOS, configuration changes can create **generations**, or saved system versions you can return to. Read [Updates and rebuilds](updates.md) and [Recovery](recovery.md) before a major system update.

> **You don't need to customise the underlying Nix files just to make the desktop look good.** Start with Ryoku's own visual settings.
