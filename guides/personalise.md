# Make Ryoku yours

Ryoku is designed to be customised from the desktop. You can change a surprising amount without opening a configuration file.

## Wallpapers and colours

Open Ryoku's wallpaper tools, including **Ryogami** where available. Choose an image, apply it and watch the supported UI colours adapt. The automatic palette system takes colours from your wallpaper so panels, widgets and accents can feel coordinated.

## Bars and launchers

Use **Ryoku Hub** to find the sections for your bar and app launcher. The available options depend on which RyoStore products are installed.

A **bar** is the strip of controls and information on your desktop. An **app launcher** is the menu or screen used to open programs. They are separate things, even if a particular bar comes with its own launcher design.

After changing a launcher, use the launcher shortcut or button to make sure the new one actually opens. If you install something experimental, keep the default option available as a fallback.

## RyoStore

RyoStore is Ryoku's catalogue of visual extras. Browse by category and read what an item changes before applying it. Some items add custom appearances, others need platform-specific packages.

> **NixOS detail:** Content such as themes is often shared with Ryoku on Arch, but system packages are managed differently. Don't blindly follow Pacman or AUR instructions on NixOS.

## Hyprland or Niri?

Both are **window managers**. They decide where windows appear and how they move. Ryoku supports both, but not every layout setting has a matching option in both.

You don't have to learn both. Start with the one selected during installation and switch only when you have a reason.

## Keep changes easy to reverse

Try one change at a time, check that it works, then continue. For a full desktop overhaul, keep a copy of your existing configuration or rice first.
